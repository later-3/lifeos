# 任务（总类）与两类任务

## 任务（总类）

有目标、需要落盘、需要可追溯的**工作单元**。
（不是"待办"：待办是一句话；任务有目录、有说明、有记录。）

## 两类任务（按「谁决定开始」分）

| 词 | 是什么 | 谁发起 | 生命周期 |
|---|---|---|---|
| **用户下达任务** | 交互 harness 协议里的任务：用户在对话里下达的工作单元（如"做个需求""定位这个问题"） | 用户 | 一次性：做完即收束（可能跨多轮） |
| **Agent 定时任务** | 由**时间或事件**触发、无人值守执行的任务 | 系统 | 长期存在、**反复运行**；有状态（启用/暂停/取消）与每次运行历史 |

**关系**：两者**同宗同源**——共用同一命名空间与字段（`taskType` 领域、`taskCategory` 类别）、同一目录约定（一个任务一个目录）；
区别只在**触发方式与生命周期**。两类都属于**任务（总类）**，都是"任务"，不存在两套并行的任务概念。

## 一次运行（run）

**定时任务**每次触发产生的一次执行。一次运行 = 一次会话 + 一条运行记录 + 一份产出（产出写进任务目录或既有约定位置）。
用户下达任务没有"运行"概念（它是一次性工作单元）。

## 层级（等级）

```
任务（总类）
├─ 用户下达任务
└─ Agent 定时任务
   └─ 一次运行（run）
```
任务类型（`taskType`）在两类任务之上**共用**：领域 → 类别 → 步骤模板，层数不限（判据：能不能跨任务复用）。
