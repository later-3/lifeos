# Agent × 项目

这里是一个 Agent 在某个项目下的空间（协议 §4.2），只属于该 Agent。

- `sessions/`：会话（原始对话记录，属于本层）；
- `tasks/`：任务，每个 Task 一个目录；默认 Task 是日常对话的入口；
- `concept-space.md`、`flywheel.md`、`specs/`、`cases/`、`knowledge/`、`tools/`、`todo/`、`memory/`、`task-types/`：与其他协作层相同的结构。

默认项目 `workspace` 是 Agent 没有添加任何项目时的交互场所，结构与其他项目相同。
