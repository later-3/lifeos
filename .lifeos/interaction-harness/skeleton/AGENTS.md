# skeleton/

目录说明与产物模板的唯一事实源（协议 §5.2）。

- **目录说明**：文件名 = 对应目录名（如 `specs.md` 是一切 `specs/` 目录里 `AGENTS.md` 的模板）。每份说明写两层：这个目录是干什么的 + 里面的产物要满足什么"内容要求"（如案例的正反与四段叙述、规范的可检查、待办的三要素——都在各文件内）。
- **层根说明**：`layer-*` 是协作层根目录（共享层 / Agent 本身 / Agent × 项目）的说明；`task.md` 是单个 Task 根目录的说明。
- **文件类产物的空模板**：`flywheel.md`、`concept-space.md` 是各层同名文件的初始骨架（不是目录说明）。

改说明内容 = 改本目录对应文件；代码只按结构复制，不另写文字。安装副本与仓库模板必须保持一致（协议对账条款）。
