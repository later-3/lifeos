# 日常 Task（daily）

> 角色：任务类型规则　类型：规则　状态：现行

默认 Task 属于这一类。每个 Agent × 项目一个，承载日常对话。

## 承载什么

- 用户还没想好要创建什么 Task、或要做什么 Task 时，随意的交互归到这里；
- 当天的沉淀写进 `daily/<YYYY-MM-DD>.md`：结论、决定、待办、案例线索、可复用经验线索；
- 原始对话留在会话记录里，这里不复制；
- 具体工作一旦明确，就建普通 Task（`development` 或 `general`），不在这里长期展开。

## 怎么维护（按天）

- 日期按本地日期切分。发起对话（每轮交互）时，若当天的 `daily/<日期>.md` 不存在，就建它，只放标题；
- 没有交互的日子不建分片：一周没有会话，就没有这一周的分片；
- 当天内容追加，带时间；不改写历史；
- 跨天时会话仍指向本 Task，新的一天写进新的分片；
- 天数多了（以几十天计）按月分组，分组规则在这里补充；
- 本 Task 不完成，也不删除。

## 与其他层的关系

- 可复用的经验提升到所在层的 `flywheel.md`；
- 只针对一件具体工作的经验，留在那件工作的 Task 里。
