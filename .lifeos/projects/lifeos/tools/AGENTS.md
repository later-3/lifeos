# tools/

工具：反复做的操作，做成可以直接用的东西（协议 §3.5）。

- 一个工具一个子目录，子目录里有说明书（`AGENTS.md`）与实现；
- 说明书写清：做什么、什么时候用、输入输出、有什么副作用；
- 放在它的归属层：只跟某个 Agent 相关的，放在该 Agent 的层里；
- 注册给运行时（如 Pi）是可选的，天生需要的才注册。

## 现有工具

| 工具 | 干什么 |
|---|---|
| `dev-port/` | 开发实例的端口分配与登记（`claim` / `list` / `release`） |
| `session-state/` | 会话状态的**四层核对**：用户报"数字对不上"时先跑它（`pnpm state`） |
| `session-trace/` | 单条会话的**交互时间线**：用户报"发不出消息 / 不知道卡在哪"时先跑它（`pnpm trace`） |
