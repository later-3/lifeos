# 文件浏览器设计（Pi Web 同型 · 分阶段实施与验证）

> 页面文档；统一规范见 [`frontend-spec.md`](../../specs/frontend-development/frontend-spec.md)；本页只写文件浏览器的数据、关系、交互、状态。

## 背景

- **页面**：文件浏览器（第 3 列文件区块 + 右侧文件面板）。
- **入口**：第 3 列“文件”区块；主区头部的文件面板开关。
- **结构**：左侧文件树 + 右侧面板（页签行 + 查看器）；两栏可独立拖宽。
- **代码**：`frontend/src/FilePanel.tsx`、`frontend/src/FileTree.tsx`、`frontend/src/useFilePanel.ts`。
- **使用方**：用户查看/打开 `~/.lifeos` 或已注册目录里的文本文件。
- **为什么需要**：让 task/案例/todo/每日记录在网页上看得见，不必离开 Life OS。

> 角色：设计　类型：结构定义　状态：实施完成待终审（2026-10-17；四步法：拆解→局部(P1 18/18、P2 7/7、P3 7/7)→合成(10/10，含性能实证)→**改版复验 10/10**→用户终审）
>
> **改版（用户 2026-10-17 终审意见）**：① 树从第3列搬入右面板 = 独立区域 [文件夹树 | 查看器]，两栏各自独立拖宽（树列宽 c4t，查看器保底 200px）；② 拖宽方向修正——c4 把手在面板**左**缘，符号取反（右拉=变小，已实测 ±90 精确）；③ 面板开合钮移到顶栏最右缘；④ 删除未要求过的面包屑；⑤ 面板默认宽 420→600（树获得完整拖动行程），旧存储无 c4t 自动整体重置为新默认（一次性迁移）。

## 0 目标与范围

**做**：左栏第 3 列内新增“文件”区块（树，根默认 `~/.lifeos`，可切换根）+ 右侧文件面板（文件页签 + 查看器），点树中文件 → 右面板打开该文件。目的是让 task / 案例 / todo / 每日记录在网页上看得见。
**不做（登记后续）**：上传、Git 变更列表、语法高亮、图片/音频/文档/diff 视图、下载（先做复制）。

## 1 三态规格（对照 Pi Web 源码逐项对应）

| 状态 | 规格 | Pi Web 对应 |
|---|---|---|
| **点开文件** | 树中点文件 → 右面板自动打开；页签行出现 `file:<路径>` 页签（同文件聚焦不重开）；查看器显示：工具栏（等宽路径 · 大小 · 渲染/源码/换行切换 · 复制）+ 内容（md 渲染 / 源码行号） | `AppShell.handleOpenFile` → `openFileTab` + `setRightPanelOpen(true)` |
| **收起** | ① 右面板顶栏图标开合（页签留内存）② 文件区块标题 chevron 独立收起（0.15s 旋转、状态持久化）③ 三列折叠维持现状互不影响 | `rightPanelOpen` / `explorerOpen`(持久) |
| **整体页面** | 左（三列级联 + 第3列内文件区块）｜中聊天｜右文件面板（页签行36px + 查看器）；全部收起时聊天最大化 | `SessionSidebar`(会话+File Explorer section) + ChatWindow + `file-panel` |

## 2 拆解（局部 · 完成标准 · 验证方式）

### P1 后端 `/api/fs`（安全白名单）
| # | 点 | 完成标准 | 验证 |
|---|---|---|---|
| P1.1 | 根白名单 = **打开过的目录历史** | 默认根=`resolveHome()`（永远第一）；额外根注册于 `config/file-roots.json`（schemaVersion），**按最近使用排序**（重复打开只提前、不重复）；`POST /api/fs/roots` 校验存在+是目录，规范化后持久 | 单测：注册/重复/不存在→404/**MRU 顺序** |
| P1.2 | `GET /api/fs/tree` | 列目录 `{path, entries:[{name,isDir}]}`，目录优先字母序，含点文件；**resolve 后必须落在根内**（`../` 越权→403 `path_not_allowed`） | 单测：越权/未注册/正常 |
| P1.3 | `GET /api/fs/content` | 文本内容+size；>2MB 截断标 `truncated`；前8KB含NUL标 `isBinary` | 单测：读取/二进制/截断 |
| P1.4 | `GET /api/fs/browse` | 选择器专用：任意路径列**子目录名**+parent（只列目录不读文件——这是“打开任意目录”与“读文件”的边界） | 单测：非目录→400 |
| P1.5 | `GET /api/fs/roots` | 返回全部已注册根（家目录第一，其余按最近使用） | 单测 |

### P2 第 3 列“文件”区块（树）
| # | 点 | 完成标准 | 验证 |
|---|---|---|---|
| P2.1 | 区块结构 | 会话下方、顶部分隔线；标题行=chevron（旋转动画）+ 根名 + 刷新（完成绿勾2s）+ 选择目录钮；收起状态持久化 | 浏览器：收起→刷新仍在 |
| P2.2 | 树 | **懒加载**（展开才拉子级）+ `Map<path,entries>` 缓存不重拉；目录行=chevron+图标，文件行=图标；点文件→`onOpenFile` | 浏览器：反复展开无重复请求（网络面板） |
| P2.3 | 切换根 | 点区块头的**根名**→「切换目录」模态（列出**打开过的目录**，最近使用在前，当前项高亮；底部「浏览其他目录…」打开原目录选择器，**从当前目录开始**、路径输入框自动聚焦并在长路径时滚到末尾让最深一段可见）→ 选中即注册（幂等，同时提到历史最前）→ 整树换根并清缓存 | 浏览器实测：.lifeos ↔ ~/Code 来回切换；契约：切换框能打开并列出历史、选择器从当前根开始 |

### P3 右侧面板（页签 + 查看器）
| # | 点 | 完成标准 | 验证 |
|---|---|---|---|
| P3.1 | 面板 | 右侧独立区，可拖宽（复用列宽系统 `c4`，持久化），顶栏图标开合（持久化） | 拖宽/开合→刷新保持 |
| P3.2 | 页签行 | 36px：文件图标+名+×（hover）、点击切换、中键关闭、同文件聚焦；页签列表持久化（localStorage，内容不入 localStorage） | 浏览器交互 |
| P3.3 | 查看器 | 工具栏：等宽路径(title)、大小、**渲染/源码**（仅 md 有渲染）、**换行**切换、复制；内容：md=marked+DOMPurify 渲染（自带紧凑样式），源码=行号+可选换行 | 浏览器：开 md/文本各一 |
| P3.4 | 每页签状态 | 显示模式/换行/滚动位置按页签记忆（滚动位置**只存组件内 ref**，不触发全局重渲染） | 切走切回原样 |

### P4 合成与整体验证
- 全链体验：选目录 → 树展开 → 点文件 → 页签/查看器 → 面板开合 → 三列折叠互不干扰；
- **性能红线**（用户红线）：树懒加载不整页重拉；页签/滚动/开合**不触发聊天与三列重渲染**；内容按需取、切页签不重拉；2MB 截断；实测展开/切换无卡顿。
  **实证（P4，performance 资源计数）**：树同目录折叠再展开 = **0 次重拉**；切页签回访 = **0 次重拉**；
  **视口挤压保护**（验收中发现并修复的真缺陷）：固定列宽可能把主区挤到 0（头部溢出到面板底下），现按视口钳制面板宽度、不足 320px 自动收面板（窄窗 1050 实测）；
- 回归：`pnpm test`（14+新增）、typecheck、build；Playwright 全链验收；最后交用户终审。

## 3 实现取舍（“能用多少参考代码”的拿捏）

- **形态、行为、交互逐项对齐 Pi Web**（表格即映射）；
- **代码不直接搬**：Pi Web 是 Next.js + CSS 变量 + 内联样式 + i18n + 上传/Git/移动端，我们是 Vite+React+Tailwind 单体 → 行为照抄、实现按我们栈**精简自研**（树 ~200 行 vs 其 1000+ 行，砍掉本期范围外功能）；
- **性能策略自定**：懒加载+按路径缓存、局部状态不出区块/面板、滚动状态只进 ref、内容按页签缓存；
- Markdown 用 `marked + dompurify`（成熟快速、渲染含表格、安全链完整——自研渲染器在表格/嵌套列表上会失真）。
