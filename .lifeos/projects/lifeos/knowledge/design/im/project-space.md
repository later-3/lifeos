# 页面：项目空间（覆盖层）

> 角色：设计　类型：页面设计（IM 版 v2）　状态：**设计中**（demo 已实现，未落地）
>
> 数值来自 [`design-language.md`](./design-language.md)。demo 实现：`Work()`；样式 `.work` / `.stat` / `.card`。
> 手机上是「项目 Tab」屏；桌面是覆盖层（rail 第二格 / 第二列分组头 `▤` / 任务条三处入口）。

## 1 职责

**这一屏回答："这个项目里现在有什么人、在干什么、最近聊了什么。"**

- 是项目的**工作台**，不是"项目的属性编辑页"。
- **不负责**：切同事（回第一列）、读消息（进会话）、项目设置（未来单独表面）。

## 2 区域构成

| 区域 | 职责 | 放什么 | 不放什么 |
|---|---|---|---|
| header | 命名项目 + 一眼看成员 | 项目图标、项目名、成员头像组 | 创建时间、路径、统计数字（与统计条重复） |
| 统计条 | 项目的**三个项目级数字** | 进行中任务、参与同事、对话总数 | 个人视角数字（我的未看） |
| 任务卡 | 项目在做的事 | 任务名、类型徽标、当前步骤、执行同事、进行中标记 | 已完成任务（进"全部"）、别的项目的任务 |
| 近期对话卡 | 跨同事的最近活动 | 标题、同事名、时间、进行中绿点 | 只显示当前同事（原实现的口径错误，见 §3） |
| 同事卡 | 谁在这个项目里 | 头像、名字、角色、生成中/空闲 | 全量同事名单（未加入的同事只作为邀请入口出现一次） |

## 3 修掉的三个根因问题

### 3.1 统计条三个数字作用域不一致（口径缺陷）

- 原来：`进行中任务`（项目级）× `未看对话`（**只算当前同事**）× `对话总数`（只算当前同事）。
  同一行三个数字，两个口径，用户无法横向比较 —— 与 C126 同类（一个位置的数字必须只有一种含义）。
- 处理：统计条**只放项目级事实**：`进行中任务` / `参与同事` / `对话总数`（三者都按项目算）。
  "未看"是**某个同事的个人视角**，它属于消息流与同事行，不属于项目工作台。
- 规则（必须）：一个统计条的每一项必须同作用域；不同作用域的指标不进同一条。

### 3.2 header 的副行是假数据 + 错别字

- 原来副行 `2026-08 创建 · 0`：那个 `0` 是一个恒为 0 的 `reduce` 占位（假数据），创建时间与"现在要干什么"无关。
- 处理：副行改为**成员头像组**（真实关系：谁在这个项目里）；创建时间不显示。
- 原来同事卡头部动作写作「治谈 ›」（错字）→ 「洽谈 ›」。
- 规则（必须）：**界面不渲染占位/假数据**。没有数据就不显示那个元素，不用 `0` 撑结构。

### 3.3 header 的状态药丸语义错误

- 原来 `1 人 / 项 在工作`（`pillrun`）既不是人数也不是项数，读不出含义。
- 处理：改为「N 项进行中」，与统计条第一项同源；没有进行中任务时整颗药丸不渲染。

## 4 状态

| 状态 | 表达 |
|---|---|
| 有任务 | 任务卡列表，进行中排前，已完成降透明（opacity .55 → 颜色改 ink-500，不用透明度，避免对比度掉到 4.5 以下） |
| 无任务 | 卡内空态：一句说明 + 「登记第一个待办」 |
| 无对话 | 卡内空态：「该项目还没有对话」+ 开新对话入口 |
| 无未加入同事 | 不显示邀请虚线框（全部已加入时不制造动作） |
| 加载 | 统计条与卡片显示骨架（demo 无后端，未覆盖；落地时补） |

## 5 交互

- 点任务卡 = 进对应会话（任务与会话一一绑定时不出现"猜"的跳转；demo 目前回消息流）。
- 点近期对话行 = 进该会话（跨同事：同时切换第一列选中同事）。
- 点同事行 = 进该同事最近会话。
- 返回：header 左侧返回 + Esc + 系统返回（手机上是一层导航）。

## 6 布局与参考

- 桌面：覆盖层铺满主区（不遮 rail）；统计条 3 等分；内容 3 列网格（任务 / 近期对话 / 同事）。
- 参考：飞书项目工作台（统计 + 卡片分组）、Zulip 的组织视图（活动流）。借**卡片分组的组织方式**，不借品牌视觉。

## 7 验收断言

1. 统计条三项同作用域（项目级），且每项都能在文档里写出定义。
2. header 不出现恒为 0 或与页面职责无关的数据。
3. 「N 项进行中」与统计条"进行中任务"数值一致；N=0 时药丸不渲染。
4. 卡片空态都有主操作；未加入同事只在真正有未加入者时出现一次。
5. 文字对比度 ≥4.5；降级状态用颜色不用透明度。
