# 页面：开新对话（模态）与新建项目空态引导

> 角色：设计　类型：页面设计（IM 版 v2）　状态：**设计中**（demo 已实现，未落地）
>
> 数值来自 [`design-language.md`](./design-language.md)。demo 实现：`Modal()` / `Guide()`；样式 `.modal` / `.px` / `.guide`。
> 两个表面放在一份文档里，因为它们是**同一条任务链的两段**：选不到合适的项目 → 就地新建项目 → 回到会话。

## 1 职责

**开新对话**：回答"这段对话记到哪个项目名下"。
**新建项目引导**：回答"刚建的项目，下一步做什么"。

- 两者的共同前提（模型 B 的核心）：**会话属于「同事 × 项目」**，所以开新对话必然要落到一个项目上。
- **不负责**：给会话命名（首条消息派生）、选模型（属于会话设置）、选同事（在 header/第一列已确定）。

## 2 区域构成

### 2.1 开新对话（modal-form）

| 区域 | 职责 | 放什么 | 不放什么 |
|---|---|---|---|
| 标题 | 命名动作 + 对象 | 「和 {同事} 开新对话」 | 说明性长文案 |
| 说明 | 一句解释为什么必须选项目 | 副行 meta 12 ink-500 | 教程、示例 |
| 选项列表 | 选项目 | 每个项目一行；当前项目带「当前项目」标记并**默认选中** | 会话列表、任务 |
| 次操作 | 就地新建 | 「＋ 新建项目…」 | 与其他选项同样式（必须视觉区分） |
| 主操作 | 确认 | 「开始对话」（44 高，全宽） | 第二个主色按钮 |

- **零选择定律**：同一项目继续办事是常态，所以默认勾选当前项目 → 用户直接点主操作。
  跨项目才需要一次点选（这是 Zulip `stream + topic` 容器的同构映射：频道=项目、话题=会话）。
- 选项的选中态用 `accent` 描边 + `accent-soft` 底，不用单选框（单选圆点在长中文项目名下会挤）。

### 2.2 新建项目空态引导

| 区域 | 职责 | 放什么 | 不放什么 |
|---|---|---|---|
| header | 返回 + 命名新项目 | 返回、项目图标、项目名、状态说明「刚创建 · 还没有对话」 | 统计、编辑入口 |
| 引导卡 1 | 第一件事：拉人 | 一句做法 + 可点整卡 | 同事全名单 |
| 引导卡 2 | 第二件事：登记待办 | 一句做法 + 可点整卡 | 表单 |
| 主/次操作 | 出口 | 「邀请同事并开始」/「跳过」 | 第三选项 |

- 空态的原则（`frontend-spec` §8 `empty`）：一句解释 + 主操作；这里有两步时用两张卡，不再加第三条说明文字。

## 3 状态

| 状态 | 表达 |
|---|---|
| 默认 | 当前项目已选中 |
| 切换选中 | 高亮随点击移动，标记文字同步（只有一个「当前项目」） |
| 无项目 | 只剩「＋ 新建项目…」，主操作禁用并说明原因（demo 未覆盖，登记 todo） |
| 新建完成 | 关闭模态 → 项目出现在分组列表 → toast 一句结果（toast 不替代列表里的新行） |

## 4 交互

- Esc / 点遮罩关闭；焦点进入模态并循环在模态内；关闭后焦点回到触发按钮（`frontend-spec` §5）。
- 点「＋ 新建项目…」= 关闭模态 → 打开空项目引导（不叠加两层模态）。
- 引导页「跳过」= 回消息流，项目保留（已创建就是已创建，跳过只是不邀请人）。

## 5 布局与参考

- 模态宽 440、圆角 14（大面档）、padding 16、选项行 44。
- 参考：Zulip 的 `stream + topic` 创建流（默认当前 stream，减少一次选择）；飞书新建文档后的空态引导（两步卡片 + 主次操作）。

## 6 验收断言

1. 打开模态时当前项目已被选中，主操作可一步完成。
2. 选中态标记只有一个，且与主操作实际使用的项目一致。
3. 模态内不出现第二层模态；新建项目走整页引导。
4. 所有选项行高 ≥44；遮罩点击与 Esc 都能关闭；焦点不逃出模态。
5. 空态卡片只有"一句做法 + 一个动作"，没有装饰性长文案。
