# 页面：同事流（第一列）

> 角色：设计　类型：页面设计（IM 版 v2）　状态：**设计中**（demo 已实现，未落地）
>
> 数值全部来自同目录 [`design-language.md`](./design-language.md)，本文不重复字号/颜色值。
> demo 实现：`demo/lifeos-im/app.js` 的 `ColAgents()` + `Rail()`；样式 `.rail` / `.row`。

## 1 职责

**这一列回答："我在跟谁干活，各自现在什么状态。"**

- 是同事（Agent）的**全集**，不是"最近用过的"。
- 一行 = 一个同事 + 他最后一次对话的一句话 + 他的状态（进行中 / 待看几条）。
- **不负责**：选项目、选会话、看消息正文、看任务。这些分别属于第二列、第三列、项目空间。

## 2 区域构成

| 区域 | 职责 | 放什么 | 不放什么 |
|---|---|---|---|
| 导航轨（rail，44 宽，`frontend-spec` §3） | 一级导航：消息 / 项目 / 同事 / 我 | 4 个图标 + 当前项高亮 | 计数、文字 label |
| 列头 | 声明"这一列是什么" + 该列主操作 | label「同事」+ 总数 | 选中同事名（选中态由行的选中底表达） |
| 同事行 | 一个同事的全部可见信息 | 头像、名字、角色徽标、最后一句预览、状态（绿点/待看数/时间） | 项目名（一行只讲一个人）、按钮 |

**为什么列头不写"同事 4"以外的东西**：列头上出现的人名会与行内名字重复；列头是常驻 chrome，
它只需要让用户确认"这一列是同事"。**唯一允许的第二个元素是总数**（它是这一列的容量事实，行内没有）。

## 3 数据与关系

| 字段 | 来源（真前端） | 说明 |
|---|---|---|
| `agents[]` | `GET /api/agents` | 全集；归档的不出现 |
| 最后一句 | 该同事**最近一次会话**的最后一条（`db.last[agentId]` → 会话最后消息） | 不是该同事所有会话的最后一条 |
| 待看条数 | 该同事名下**所有项目**会话的未看之和 | 与第二列的分组计数同源（`status-map`） |
| 进行中 | 该同事任一项目的会话在跑 | 绿点，不写文字 |

- Agent : Project 是 N:M（绑定），本列按**同事**枚举，不按项目；同一项目会出现在多个同事下。
- 待看 = 会话级计数之和（不是项目数），口径与 `knowledge/architecture` 的未读模型一致。

## 4 状态

| 状态 | 表达 |
|---|---|
| 默认 | 头像 + 名字 + 预览 + 时间 |
| 进行中 | 行尾绿点（8px），预览仍显示最后一句 |
| 有待看 | 行尾绿色数字徽标（micro/700），替代时间 |
| 选中 | 行底 `accent-soft`；预览色 ink-700（提高对比，不换字号） |
| 空 | 只有一个同事也没有时：一句说明 + "创建一个同事"主操作（demo 未覆盖，登记 todo） |

**槽位固定**：行尾上=时间、下=待看徽标；进行中在标题行最前。两列（同事 / 对话）槽位一致，
同一信息不因在哪一列而换位置。

**数字槽只有一种含义**：待看徽标 = 待看会话数。进行中用绿点表达，不占数字槽 —— 一个位置两种含义
会让用户无法判断"3"是三条未读还是三个在跑（这是 C126 的同类缺陷）。

## 5 交互

- 点击行 = 切到该同事 + 直接进入**他最近的那次会话**（模型 B：不落在中间层）。
- 键盘：行可聚焦（`tabindex=0`）、Enter 等同点击、方向键上下移动焦点（demo 未实现，登记 todo）。
- 悬停：整行底色 `hover`，不出现"更多"按钮（同事的次级动作在同事详情里）。
- 手机的同一内容改由「消息流」屏承载（全屏行，行高 56，见 `specs/frontend-mobile/mobile.md`）。

## 6 布局与参考

- 桌面：固定 264 宽列，行 56 高（双行），头像 32。
- 参考：Zulip 侧栏（对象行 + 分区标题 + 未读徽标）、Telegram 对话列表（预览 + 时间 + 徽标三槽）。
  借**信息槽位**（头像 / 名字+预览 / 状态+时间），不借配色与圆角。

## 7 验收断言

1. 每一行同时最多出现一个数字徽标，且该徽标恒表示待看会话数。
2. 列头不出现当前选中同事的名字。
3. 行内文字只用 micro/meta/body 三档；行标题 = body 13.5/600。
4. 任何文字颜色对比度 ≥4.5（含 hover 态）；ink-300 不出现于文本节点。
5. 行可点区域高 ≥44（桌面 ≥44 取整，手机同值）。
