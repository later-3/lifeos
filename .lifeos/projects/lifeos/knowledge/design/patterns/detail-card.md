# 模式：detail-card（实体信息卡）

> 角色：交互模式　类型：模式（frontend-spec §8 第一次使用即抽，用户 2026-11-13 要求统一，不再每个功能自创卡片）
> 首个实现：`frontend/src/project-overview.tsx`（项目概览卡，Task 0010）

## 何时用

"看一眼某个实体的**摘要 + 少量低频动作**"：不编辑、不导航，从行内就地弹出。
（要**编辑字段** → modal-form；要**长内容/多面板** → 常驻面板；要**全页工作台** → 独立页面。）

## 结构（三区，写死顺序）

| 区 | 内容 | 规则 |
|---|---|---|
| 身份区 | 图标 + 实体名；下方一行路径/副标题（可复制） | 只读事实；没有就写清"它是什么"（如"默认工作区"），**不放假数据** |
| 数据区 | label 上、count 下的统计格（2–3 列栅格） | 一格一个数字一种含义（frontend 2.15）；计数 0 是真实数据照常显示 |
| 次级动作区 | 细线分隔后的低频动作 | **与数据区视觉分级**：危险动作用 `ghost-danger`（文字 danger、无实底、hover 染 danger-soft）+ confirm；不放主操作 |

## 入口（行内怎么打开）

**行内专用图标钮，不藏在数据里**（点数字/点徽标 = 不可发现，2026-11-13 用户否决"点计数"）。
可见性由用户拍板：**本项目当前 = 常显**（三轮拍板："直接固定吧，不要鼠标移动上去再显示"——可发现性优先于密度）；
hover 显形（Row/SessionRow 的同格互换机制）仍是行内**低频动作**的默认形态（助手行 ⚙/🗑、会话行三个动作钮）——
一个行内是"常显概览钮 + hover 动作"并存：**主入口常显，低频动作 hover**。

## 容器与行为

- 容器 = `design/popover-view.tsx` 的 `Popover`（定位/Esc/点外关/焦点归还都是基建，不自己写浮层）；
- 四态（testing 2.3）：加载骨架 / 失败+重试 / 成功 / 计数 0 照常；
- 数据获取：打开即取、关闭即弃；与行上已有的同一事实**共用一份数据**（api 2.10），不重取第二份。
