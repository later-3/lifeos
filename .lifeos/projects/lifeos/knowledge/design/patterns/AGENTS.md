# patterns/

交互模式的正式沉淀（frontend-spec §8）：一个模式一份文档，写"何时用 / 结构 / 入口 / 容器 / 现有使用者"。

## 什么时候读

给一个新表面（卡片/浮层/编辑表单）选形态时，先来这里对号入座；模式覆盖不到的，先在页面文档写草案，第二次复用时再抽进来。

## 怎么用

- 新表面**必须**引用已有模式而不是另起炉灶（用户 2026-11-13：不许每个功能自创一种呈现）；
- 模式变化时，检查文档里列出的全部使用者；
- 目录下每个 `.md` 就是一个模式，文件名 = 模式 id。

## 里面有什么

- `detail-card.md`：实体信息卡（快看语义；首个实现 = 项目概览卡，Task 0010）。
