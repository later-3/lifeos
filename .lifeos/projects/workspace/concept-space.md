# 概念空间（共享 workspace）

> 角色：概念　类型：定义　状态：现行

概念空间只解释概念：它是什么、在具体场景下是什么、它不是什么（协议 §3.2）。一个概念只定义一次；规则写进规范，事实写进案例或日志。

| 词 | 是什么 | 在具体场景下是什么 | 不是什么 |
|---|---|---|---|
| 交互 harness | 用户与 Agent 长期协作时，让"怎么协作"可以被积累、遵守、复用的协议 | 放在 `interaction-harness/` 下，由装配层读取进 prompt | 不是某个项目的规范，也不是产品实现 |
| 飞轮 | 行动 → 记录 → 提炼 → 下一次更好 | 思想是一种做事方式；飞轮文档是每层一份的可复用经验 | 不是过程日志，不是任务清单 |
| 概念空间 | 词的定义处 | 每层一份 `concept-space.md`，只收本层需要定义的词 | 不记日志、不写规则、不记事实 |
| 规范 | 在具体场景下，怎么做才是对的（讲清本质，写应该或不应该） | 放在 `specs/<主题>/`，逐层追加加载 | 不是 Skill，不是协议本身，不是案例 |
| 案例 | 发生过的事实，分正例与反例，可带其他标签 | 按日期写进发生的那一层的 `cases/` | 不是提炼出的规则（规则进规范或飞轮） |
| 日志 | 一件事做了什么、发生了什么、哪些要记下来 | 开发类 Task 的 `log.md`；日常 Task 的 `daily/<日期>.md` | 不是经验（经验进飞轮），不是原始对话 |
| 知识库 | 可复用的领域知识，带出处 | 按主题组织的文档，放在 `knowledge/` | 不按时间组织 |
| 工具 | 反复做的操作，做成可以直接用的东西 | 放在归属层的 `tools/<工具>/`，配说明书 | 注册给运行时是可选的，不是工具的定义 |
| 待办 | 还没成为任务的一句话 | 放在所在层的 `todo/` | 不是任务，没有目录与类型 |
| 任务（Task） | 有目标、需要落盘、可追溯的工作单元；Agent 与用户的交互以它为粒度 | 目录 `tasks/<NNNN>-<标题>/`，`task.md` 为唯一状态源 | 不是待办；不是一次会话 |
| 任务类型 | 同一类 Task 的规则与文件骨架 | `task-types/<类型>/`：`template.json`、`TEMPLATE.md`、`AGENTS.md` | 不是 Task 本身 |
| 默认 Task（日常） | 每个 Agent × 项目一个，承载日常对话，按天分片 | 类型 `daily`，`tasks/0001-default/`，内容在 `daily/` | 不是某件具体工作，不会完成或删除 |
| 普通 Task | 用户下达的具体工作 | 类型由模板定义（如 `development`、`general`，可扩展）；状态是记录，可随时改回进行中 | 不是日常对话的落点 |
| Task ID | Task 在所属层内的稳定编号 | 四位连续编号 `NNNN`，目录名 `NNNN-标题`，`task.md` 写 `ID:` | 标题可以改，ID 不变 |
| 指针（activeTaskId） | 会话当前引用的 Task | 会话里的一条记录；每轮开始读取 | 不是绑定；不会把内容复制进会话 |
| 说明文件（AGENTS.md） | 目录的说明：里面有什么、怎么用 | 每个目录都有一份；外层说明子项，内层说明自己 | 不是规则本身（规则在规范里） |
| 协作层级 | 内容属于谁、谁必须遵守的层 | 共享 workspace、共享项目、Agent × 项目、Task、会话、轮次 | 不是目录深度 |
| Agent 本身 | Agent 的配置、身份、独有的工具与记忆 | `agents/<id>/` 根目录 | 不是协作层级，不设飞轮与案例 |
| workspace | 默认项目：共享 workspace 与 Agent 的默认项目同名、不同层 | 共享的 `projects/workspace/`；每个 Agent 的 `projects/workspace/` | 默认项目的结构与其他项目相同 |
| 会话 | 一次连续对话的原始记录（JSONL） | 属于 Agent × 项目的 `sessions/` | 不是日志，也不是沉淀 |
| 轮次 | 一次用户输入与 Agent 回复 | 会话中的一次运行 | 不是任务 |
| 记忆 | Agent 的能力：记住什么、记在哪一层、怎么用 | 四层记忆与三个操作，见协议 §3.11 | 三个工具的实现属于落地层 |
| 作用域 | 谁必须遵守某条内容 | 与协作层级一致，加载时从外到内逐层追加 | 不是覆盖关系 |
| 提升 | 把低层内容升到更高层 | 移动正文，原处留指针；不复制 | 不是复制一份 |
| 内容要求 | 某目录的产物"必须包含什么"的条款 | 写在协议目录 skeleton 的 dir-*.md 里，由 AGENTS.md 生成引用 | 不是格式模板；也不是任务内容 |
