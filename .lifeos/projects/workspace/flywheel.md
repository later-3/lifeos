# 飞轮（共享 workspace）

> 角色：经验　类型：文档　状态：现行

飞轮是可复用的经验：反复奏效的做法、反复踩的坑、以及为什么（协议 §3.1）。本文件只放对**所有 Agent** 都适用的经验。

- **骨架与安装类改动：模板是唯一事实源。** 文档抄模板、代码只做复制，不在代码里另写目录清单。（依据：2026-10-17 案例 C001、C002）
- **安装一次性，启动只校验。** 任何“每次启动都写入”的逻辑，先问一句：它会不会覆盖用户改动？（依据：2026-10-17 案例 C001）
- **设计点先拍板再动手。** 出设计说明（含选项与推荐）→ 用户逐条批 → 才改代码；实现轮只执行已批清单。（依据：2026-10-17 案例 C004）
- **协议、模板、安装副本、代码四者必须同轮对账。** 模板是源，安装副本是运行时；发现副本停在旧设计时先确认源，再同步，不在两份之间“各改一点”。（依据：2026-10-22 案例 C109）
- **规范按作用域加载，模板按优先级选一份。** 规范逐层追加、不覆盖；任务模板只选第一份，不把两种机制混成“覆盖 / 合并”。（依据：协议 §3.3、§3.7、§11）
- **切换 Task 只改指针是假切换。** 每轮开始必须读取会话的 `activeTaskId`，否则界面显示的 Task 与实际加载的说明不一致；切换只影响下一轮。（依据：2026-10-22 案例 C110）
