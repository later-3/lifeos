# 共享层说明

这里是一个项目（或共享 workspace）的**共享层**：所有绑定它的 Agent 共用这里的内容。结构与其他协作层相同（协议 §5）。

## 这里有什么

- `project.json`：项目身份（唯一来源）；共享 workspace 没有 `path`；
- `concept-space.md`：概念（只解释是什么、在具体场景下是什么、不是什么）；
- `flywheel.md`：本层的飞轮（可复用的经验）；
- `specs/`：规范，按主题分目录，`index.json` 是索引；
- `cases/`：案例（正例 / 反例，按日期分文件）；
- `knowledge/`：知识库（按主题，带出处）；
- `tools/`：工具（一个工具一个目录，配说明书）；
- `todo/`：一句话待办；
- `memory/`：项目共享记忆；
- `task-types/`：本层可选的任务类型模板。

每个子目录都有自己的 `AGENTS.md`，先读它再写。
