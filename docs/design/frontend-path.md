# 前端开发路径（约束与门禁）

> 角色：开发规范　类型：机制　状态：实施中（2026-10-18 起生效）
>
> **一句话**：视觉约束不写散文，只写四种**可执行物**；散文只负责解释"为什么"。
> 依据：同一份 `frontend-structure.md` 里曾同时存在三处漂移——"主区有面包屑"（代码已删）、"`MIN_CHAT=300` 保证聊天不被挤没"（实测 252px）、"收起列留 20px 窄边"（组件实际 36px）。不是人不仔细，是散文没有执行点。

## 1 五个事实源（其它地方不许定义）

| 事实 | 唯一来源 | 谁校验 |
|---|---|---|
| 数值：字阶 / 灰阶 / 圆角 / 语义色 / 阅读列宽 | `frontend/src/design/tokens.css` | `pnpm lint:tokens` |
| 控件外观与键盘行为（按钮/图标钮/行/表单/模态/Toast/确认框/导航轨） | `frontend/src/design/{ui,overlay,toast,rail}.tsx` | `pnpm lint:tokens`（`design/` 之外禁裸控件） |
| 布局宽度：列 / 折叠成本 / 面板上限 / 聊天保底 | `frontend/src/design/layout.ts` | `pnpm test`（视口 × 折叠组合穷举不变量） |
| 消息与 Markdown 渲染（两端都渲染，禁止 HTML 透传） | `frontend/src/Message.tsx` | `pnpm test:ui`（对比度 / 裁切） |
| 几何、对比度、命中区、键盘、截图基线 | `frontend/test/ui-contract.mjs` | `pnpm test:ui` |

## 2 四道闸（提交前必须全绿）

```bash
pnpm typecheck && pnpm lint:tokens && pnpm test && pnpm test:ui && pnpm build
```

| 闸 | 拦什么 | 实现 |
|---|---|---|
| **1 token** | 任意值 `text-[13px]` / `w-[58px]` / `#rrggbb`；裸调色板 `text-neutral-400`、`bg-blue-50`；`outline-none` | `scripts/lint-tokens.mjs` |
| **2 primitive** | 页面自己画按钮/模态/表单/空态；同一控件多处实现 | 只允许从 `design/*` 导入；新增控件先落 primitive 再进页面 |
| **3 契约** | 聊天列 < 420px；宽度不守恒；折叠成本 > 44px；竖向文本裁切；hover 位移；对比度 < 4.5:1；命中区 < 28×28；模态无 `role=dialog`/焦点逃逸/Esc 失效；键盘无焦点环 | `frontend/test/ui-contract.mjs`（浏览器）+ `test/ui-layout.test.mjs`（纯函数） |
| **4 截图基线** | 视觉悄悄变了没人看 | 4 张基线（1280 / 1600 / 全收起 / 配置模态；**基线为本地产物，不入 Git**，2026-10-18 用户定），冻结时钟 + 独立浏览器 + **像素容差**（差异 > 0.05% 才判变化）；变了就 `pnpm test:ui:update` 并**人眼确认 diff** |

一键：`pnpm verify`（= typecheck + lint:tokens + test + test:ui）。定期体检：`pnpm audit:ui`（见 §8 L4）。

## 3 加一个控件的正确顺序

1. **先判定**：这是不是新控件？（新 = `design/` 里没有同形且同状态集的东西）
2. 是 → 在 `design/ui.tsx`（或 overlay/toast/rail）加 primitive：变体、尺寸、`disabled`、`focus-visible`、命中区 ≥ 28 一次做全。
3. 在 `ui-contract.mjs` 加一条断言（命中区 / 对比度 / 键盘 / 几何，至少一项）。
4. 页面里只做组装；**不写**调色板、不写任意值、不写 `outline-none`。

## 4 改布局的唯一方式

`layout({ viewport, widths, requested, panelOpen })` → `{ rail, c1..c3, panel, tree, chat }`。
- 组件里**禁止**再算一遍宽度（历史上 `fixedWidth` 按 20px、`FoldRail` 实际 36px，就是这么分叉的）。
- 折叠是**常数成本**：任一列收起 → 一条 44px 全局导航轨；全展开 → 0。绝不 36px × N。
- 不变量测试与实现同 commit 更新；测试通过不等于布局对，还要看 4 档视口截图。

## 5 视觉验收（人看什么）

- 4 档视口截图（1024 / 1280 / 1440 / 1600）+ 折叠态 / 文件面板 / 配置模态。
- 用户说"丑"时，先把它翻译成一条断言或一个数值（"每行只有 11 个字" → `MIN_CHAT ≥ 420`），再改；否则下次还会丑。

## 6 明确禁止

- 页面层出现：任意值、裸调色板、`outline-none`、`window.confirm/alert`。
- 组件各自实现：导航轨、模态、Toast、按钮、空态（要改就改 primitive）。
- 只改视觉、不回应基线 diff；或直接 `--update-baseline` 刷掉失败。

## 7 为什么这样能止住"越改越丑"

丑在代码里只有三个来源，四道闸一一对应：**散落的数值**（闸 1）、**重复实现**（闸 2）、**无人复核的几何退化**（闸 3 + 4）。


## 8 开发节奏（四层，这是"持续统一"的骨架）

| 层级 | 触发 | 时长 | 必须做的三件事 | 命令 |
|---|---|---|---|---|
| **L1 单点** | 调一处间距/颜色/文案 | 分钟 | 只改一个维度 → 看完页面 → 跑 token 校验 | `pnpm lint:tokens` |
| **L2 切片** | 加一个控件 / 一块界面 / 一个交互 | 小时 | ①三行"视觉归属判定"（新控件？复用哪个 primitive？影响哪条不变量）②新控件先落 `design/`，同轮补一条断言 ③2×2 截图（宽/窄 × 改前/改后） | `pnpm verify` |
| **L3 轮末** | 每次说"做完了" | 半小时 | 全量门禁 → 4 档截图 → ≤1 屏数字摘要 → daily 记录 | `pnpm verify && pnpm audit:ui` |
| **L4 收敛** | 每 2 周，或每积累 3 个新控件 | 半小时 | 跑体检报告看"有没有新花样"，归并进 token/primitive，不新增约定 | `pnpm audit:ui` |

**L4 的判据由脚本给**：字号 ≤ 5、圆角 ≤ 5（inner/control/panel/bubble/full）、文字色 ≤ 6、图标尺寸 ≤ 4（14/16/18/22）、小命中区 = 0、折叠轨 0 或 44。"只降不涨"。

### 8.1 触发规则（If → Then，改之前先查这张表）

| 你正在做的事 | 必须先做 | 对应闸 |
|---|---|---|
| 新控件或新状态 | 在 `design/` 加 primitive，并补一条断言（命中区/对比度/键盘） | 2 + 3 |
| 需要新数值（间距/字号/圆角/颜色） | 加进 `tokens.css`，**不许**在 className 写任意值 | 1 |
| 动布局/宽度/折叠 | 只改 `layout()`，同 commit 改不变量测试 | 3 |
| 改交互/键盘/焦点 | 补 `ui-contract` 断言 | 3 |
| 纯视觉微调 | 跑 `test:ui:update` 并人眼确认 diff（单独 commit） | 4 |
| 用户说"丑/别扭" | **同一轮**先把它翻译成一条断言或一个数字，再改 | 3 |

### 8.2 硬规则（破了就红）

1. 一个 commit 一个维度：布局 / 版式 / 交互分开，不夹带。
2. 基线更新单独 commit，附 4 张截图；禁止夹在功能里、禁止直接刷掉失败。
3. 交付报告 ≤ 1 屏：改了哪些数字、4 档截图、断言结果；细节进 daily。
4. 门禁自检：`ui-contract` 自带"检查项数量 + 关键项存在"断言——删掉一段检查会立刻红（2026-10-18 真的发生过一次基线检查块被整体删掉却"全绿"）。

### 8.3 反例（都真实发生过）

- **原地加宽**：20px 窄边 → 用户说看不见 → 加到 36px → 三列共 108px，把聊天压到 252px。缺的是"折叠成本常数化"这条约束，不是 16px。
- **散文当约束**：文档写 `MIN_CHAT=300`，实测 252；文档写"主区有面包屑"，代码已删。
- **一次性体检**：手工量过一次就以为不会再犯，下一轮开发全部回潮。
- **静默失效的门禁**：改动脚本时把基线检查块删了，测试依然"全绿"——所以门禁必须能证明自己活着。
