# 后端规范

> 角色：开发　类型：约束　状态：目标（Hello World 起生效，边做边补）

## 运行与依赖

- Node.js `>=22.19.0`，TypeScript，ESM（`package.json` 已设 `"type": "module"`）。
- HTTP 用 **Hono**；Agent 运行时用 **Pi SDK**（以源码方式 `link:` 使用 `pi/packages/*`）。
- 不引入其他框架/ORM/DI 容器；需要时先讨论。

## 目录与边界

- `src/` 下**扁平放文件**，只在成组时才建子目录（不预建空目录）。
- `src/main.ts` 进程入口；`src/server.ts` HTTP 服务与路由；`src/home.ts` 家目录安装。
- 业务逻辑与 HTTP 分开：路由只做参数校验、调用、错误映射；规则写在被调用的模块里。
- 家目录路径只从 `resolveHome()` 取；**绝不**用 `process.cwd()` 推断家目录。

## 命名

- 文件：`kebab-case.ts`；函数/变量：`camelCase`；类型/接口：`PascalCase`；常量：`UPPER_SNAKE_CASE`。
- 路由：`/api/<资源复数>/:id/...`；`:id` 是 **slug**（`^[a-z0-9][a-z0-9-]{0,63}$`），不是显示名。

## 接口约定

- 成功：返回 JSON 对象；列表返回数组或 `{ items: [...] }`。
- 失败：HTTP 状态码 + `{ "error": { "code": "not_found", "message": "人话说明" } }`；`code` 用稳定短标识，前端按它分支。
- 每个路由入口都要**校验输入**（类型、必填、边界），不信任客户端；不合法就 400。
- 长任务不等结果：受理请求立即返回引用（如 `{ turnId }`），结果通过事件流给出。

## 类型与数据

- 严格类型；**禁止 `any`**；不用断言绕过校验。
- 前后端共享的契约类型，需要时放 `shared/`（现在还没有，别预建）。
- 会话/消息等事实**只写家目录**（`~/.lifeos`），且只通过 Pi 的会话存储写入；后端不另造第二份状态。
- 写文件必须原子（临时文件 + rename）或加锁；写前校验目标路径在家目录内。

## 配置与运行

- **不设环境变量**（唯一例外 `LIFEOS_HOME`，用于引导与测试）。
- 端口：默认 `43120`，可用命令行参数覆盖（开发用）。
- 日志写 stdout；不引入日志框架。

## 测试与构建

- `test/*.test.mjs`，用 `node:test` + `node --experimental-strip-types`。
- 每个接口至少两条：happy path + 一条错误路径；测试**起真实服务**（随机端口）再发请求，不测私有实现细节。
- `pnpm build` 产出 `dist/server.mjs`（esbuild 单文件）；`pnpm start` 运行产物。

## 代码质量

- 单个函数保持短小；不写"以后可能用得上"的抽象。
- 删除死代码，不留"仅历史"注释；不做未被要求的兼容层。
