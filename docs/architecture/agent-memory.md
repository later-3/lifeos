# Agent 记忆架构（Life OS 的记忆类型）
> 角色：架构　类型：说明　状态：**第一部分（记忆类型 + 第三方依赖 + 形态）已定；机制与实现待后续**
>
> **本文是"记忆类型、形态与归属"的唯一权威**：Life OS 其他地方涉及记忆时**只引用本文**，不重复定义。

## 1 口径

1. 记忆在 Life OS 里**共 4 类**（不是只有 Agent 一类）；
2. **存储形态按类划分**：项目记忆、会话记忆、Agent 日记 = **文本（Markdown）**；用户记忆与 Agent 长期记忆 = **mem0**；
3. **mem0 是 Life OS 的第一个第三方依赖**（见 §3）；
4. **本轮只登记，不写实现方案**（也不写"自研"）——真正落地时再谈怎么替换/怎么接。

## 2 四类记忆（2026-10-15 定）

| # | 类型 | 存储形态 | 归属 | 说明 | 优先级 |
|---|---|---|---|---|---|
| 1 | **项目记忆** | **文本（Markdown）** | 属于**项目**（该项目内共用） | 项目内跨会话/跨 Agent 都要用的事实 | 后放（`todo/33`） |
| 2 | **会话记忆** | **文本（Markdown）** | 属于**会话** | 含义 = **项目记忆 × 用户记忆 × Agent 记忆 的交集**：它既属于某一个项目，又是 Agent 与用户交互产生的 | 后放 |
| 3 | **用户（个人）记忆** | **mem0** | 属于**用户**（跨项目共用） | 用户本人的稳定事实；与 mem0 **高度相关**（mem0 就是它的存储与检索） | 后放（`todo/33`） |
| 4 | **Agent 记忆** | **两类**：**日记 = 文本（Markdown）**；**长期记忆 = mem0** | **属于这个 Agent 自己** | 日记 = 按天的过程与结论；长期 = 可检索的耐久事实 | **先做** |

**判断口径**：同一事实只落**一类**——先问"这个事实跟着谁走"：跟项目走 → 项目记忆；跟用户走 → 用户记忆；跟这个 Agent 走 → Agent 记忆（日记 or mem0 长期）；只跟这一段对话走 → 会话记忆。

**Agent 记忆内部再分两种（用户定）**：
- **日记**：每天写，**文本**（Markdown）；由"定时任务"在每天固定时间触发（见 [`agent-tasks.md`](./agent-tasks.md)）；
- **长期记忆**：**mem0**；平时（对话中）由 Agent 通过工具写入与检索。

## 3 第三方依赖：mem0（第一个）

| 项 | 内容 |
|---|---|
| 是什么 | 记忆层服务/库：把事实条目化存储，并提供**语义检索**（相对"纯文件 + 关键词"检索，能按意思找到） |
| 我们装的版本 | `mem0ai@3.1.7`（`package.json`），**并带一个 patch**：`patches/mem0ai@3.1.7.patch` |
| **我们要用它的哪些方法** | `memory.add(...)`（写入条目）、`memory.update(mem0Id, ...)`（按 id 更新）、`memory.delete(mem0Id)`（按 id 删除）、`memory.search(query, ...)`（语义检索）——共 **4 个**（代码：`src/memory/mem0-index.ts:89,104,112,123`） |
| 我们怎么包它 | `Mem0MemoryIndex`（`src/memory/mem0-index.ts`）在上层封装；对 Agent 暴露的工具是 **`memory_search`**（检索）与 **`memory_record`**（写入） |
| 配置与连接方式 | 属实现细节，本文不展开；**登记为待补项**（连接/落点/凭据要在系统配置里说清，见 `agent.md` §9） |
| 为什么选它（而不是 Pi 生态的记忆包） | 质量与语义检索能力是硬需求；见 §4 |

## 4 明确不采用 `pi-memory`（2026-10-15 定）

Pi 官方目录里的 `pi-memory`（MIT、零依赖、约 46k 下载）是**优秀的参考**——纯 Markdown + 时间戳条目 + 标签 + wiki 链接 + 每日日志 + 可选语义检索。
但我们**不采用它**：Life OS 的记忆分**四类**且**长期/用户记忆用 mem0**；`pi-memory` 只作为**形态参考**（尤其"日记 = 每日日志"这一形态），不作为依赖。
